# Shin4Static

Маршрутизация выбранных сетей через VPN на Keenetic с Entware: по своим
спискам (IP, подсети, диапазоны, домены, номера AS) и с kill switch для
отдельных записей. Подробности и причины решений — в [DESIGN.md](DESIGN.md).

## Установка

```
opkg install git git-http
git clone https://github.com/shinleinen-dotcom/Shin4Static.git
sh Shin4Static/install.sh
```

Повторный запуск `install.sh` обновляет код и сохраняет настройки и списки.
Удаление: `sh Shin4Static/uninstall.sh` (с `--purge` — вместе с настройками).

Shin4Static работает своим экземпляром BIRD и не трогает `/opt/etc/bird.conf`
и системный `bird`: установленный рядом Bird4Static (работающий или нет) на
него не влияет, и наоборот. Подробнее — в DESIGN.md.

## Списки

`/opt/etc/shin4static/lists/isp.list`, `vpn1.list`, `vpn2.list` — по одной
записи на строку:

```
2ip.ru                  # через VPN1, при его падении — через провайдера
!KS0 AS555842           # только через VPN1, при падении — блок
!KS2 203.0.113.0/24     # VPN1, затем VPN2, затем блок
!FB2 198.51.100.0/24    # VPN1, затем VPN2, затем провайдер
```

После правки списков:

```
shin4static check       # проверить, ничего не меняя
shin4static update      # применить (cron делает это раз в час)
```

## Диагностика

```
shin4static status      # интерфейсы, правила, таблицы, последний запуск
shin4static why 1.2.3.4 # в какую группу входит адрес и куда он идёт сейчас
```

## Веб-интерфейс

Установщик предлагает его включить: `busybox httpd` на адресе роутера в
локальной сети (по умолчанию порт 8088), вход `admin` с заданным паролем.
Списки показаны блоками: комментарий `# …` над строками — заголовок блока,
пустая строка — граница. У каждой записи свои флажок KS, выбор резервного VPN
и заметка; KS и резерв можно задать сразу всему блоку. Отмеченные записи
переносятся в новый или существующий блок. Режим «Текст» показывает файл как
есть. На диске формат прежний — генератор и cron ничего не замечают.

Ещё можно проверять, применять, смотреть состояние и спрашивать, куда идёт
адрес. Клик по `vpn1.list:7` в выводе подсвечивает нужную запись.

Защита: доступ только из локальной сети (`/opt/etc/shin4static/httpd.conf`),
пароль, токен против CSRF (новый при каждом запуске), проверка заголовка Host
против DNS rebinding (имена кроме IP — в `WEB_HOSTS`), запись только в файлы
списков.

Запуск и остановка: `/opt/etc/init.d/S81shin4static-web start|stop`.

## Тесты

- `sh tests/run.sh` — генератор; нужны `iprange` и доступ к DNS. curl, birdc и
  ip подменяются заглушками, роутер не нужен.
- `sh tests/cgi.sh` — веб-API.
- `node tests/model.test.js` — разбор и сборка файла списка в блоки.
- Просмотр интерфейса на Windows с WSL: `sh tests/devroot.sh` в WSL, затем
  `python tests/devserver.py` и http://127.0.0.1:8099/.
